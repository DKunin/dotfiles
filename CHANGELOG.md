# Журнал изменений

## 2026-09-15

- Локальные каталоги сборки Xcode и служебные файлы Finder исключены из Git, чтобы артефакты сборки и содержащиеся в них учётные данные не попадали в репозиторий.

## 2026-08-25

- Добавлено интерактивное обновление Codex Limit: нажатие на виджет перезагружает его данные без открытия приложения.
- В средний виджет добавлено время последнего обновления с точностью до секунды.

## 2026-08-24

- Добавлен плагин xbar для отображения оставшегося лимита Codex через существующий SOCKS5-прокси.
- Добавлено нативное приложение с виджетом WidgetKit для отображения лимита Codex в «Центре уведомлений» macOS.
- Исправлена регистрация виджета Codex Limit в галерее: расширение теперь использует обязательную песочницу WidgetKit и корректную подпись.

## 2026-07-27

- Исправлена функция `uploadVideo`: вместо устаревшего WordPress-каталога она загружает видео в каталог `Videos` текущего файлового сервера.
- Добавлены проверки аргумента и существования файла, поддержка путей с пробелами и возможность продолжить прерванную передачу через `rsync`.
